# JavaScript Calculator

A working calculator built with plain HTML, CSS, and JavaScript. Click the keys or use your keyboard.

## What this project shows

- DOM event handling for both mouse and keyboard input
- Input validation before any calculation runs
- Clean state handling: one expression string, one render function, no framework

## Run it

Open `index.html` in any browser. Keys: digits and operators type, Enter calculates, Backspace deletes, Escape clears.

## Why it exists

A calculator is a classic early JavaScript project because it forces the fundamentals: state, events, edge cases, and readable code. This is my version, written cleanly and commented by structure rather than by line.
